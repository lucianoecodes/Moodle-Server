# 2. Sistema Operacional

## Detalhes do SO

| Item | Valor |
|------|-------|
| **Distribuição** | Oracle Linux Server 9.8 |
| **Hostname** | `serverlocal` |
| **Kernel** | `6.12.0-206.104.3.3.el9uek.x86_64` (UEK) |

| **Arquitetura** | x86-64 |

## Notas

- Está virtualizado em **VMware**, plataforma padrão da infraestrutura.
